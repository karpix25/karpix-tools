# Karpix Tools API

Мощный инструментарий для обработки медиа-контента, построенный на Python с использованием Flask.

## Возможности

API предоставляет широкий спектр функций для работы с медиа-файлами:

- **Конвертация аудио и видео** - преобразование между различными форматами
- **Транскрибация контента** - преобразование речи в текст с использованием Faster-Whisper
- **Автоматические субтитры** - добавление субтитров к видео
- **Обработка изображений** - конвертация, создание скриншотов веб-страниц
- **Сложная обработка медиа** - через гибкий интерфейс FFmpeg
- **Облачное хранилище** - интеграция с Google Drive, Amazon S3, Google Cloud Storage

Развертывание возможно через Docker на любой платформе: Google Cloud Platform, Digital Ocean, или любой системе с поддержкой Docker.

## Преимущества транскрибации для русского языка

API использует модель **Faster-Whisper Large-v3-Turbo** с оптимизацией для русского языка:

✅ **Высокая точность** - модель large-v3-turbo специально обучена на русскоязычных данных  
✅ **Быстрая обработка** - оптимизация int8 обеспечивает скорость без потери качества  
✅ **Работа на CPU** - не требуется дорогостоящее GPU оборудование  
✅ **Распознавание диалектов** - понимает различные акценты и произношение  
✅ **Пунктуация и форматирование** - автоматическая расстановка знаков препинания  
✅ **Экономия ресурсов** - в 4-5 раз быстрее оригинального Whisper при сопоставимой точности

## API Endpoints

Каждый endpoint поддерживает валидацию payload и подробную документацию API для упрощения интеграции.

### Аудио

- **`/v1/audio/concatenate`**
  - Объединяет несколько аудиофайлов в один

### Код

- **`/v1/code/execute/python`**
  - Удаленное выполнение Python кода с возвратом результатов

### FFmpeg

- **`/v1/ffmpeg/compose`**
  - Гибкий интерфейс к FFmpeg для сложных операций обработки медиа

### Изображения

- **`/v1/image/convert/video`**
  - Преобразует статичное изображение в видео с настраиваемой длительностью и эффектами зума

- **`/v1/image/screenshot/webpage`**
  - Создает скриншоты веб-страниц с использованием Playwright с расширенными опциями

### Медиа

- **`/v1/media/convert`**
  - Конвертирует медиафайлы из одного формата в другой с настраиваемыми кодеками

- **`/v1/media/convert/mp3`**
  - Конвертирует различные медиа-форматы в MP3 аудио

- **`/v1/BETA/media/download`**
  - Загружает медиа-контент из различных онлайн-источников используя yt-dlp

- **`/v1/media/feedback`**
  - Веб-интерфейс для сбора и отображения отзывов о медиа-контенте

- **`/v1/media/transcribe`**
  - Транскрибирует или переводит аудио/видео контент по URL
  - Использует Faster-Whisper Large-v3-Turbo для высокоточной транскрибации русского языка

- **`/v1/media/silence`**
  - Определяет интервалы тишины в медиафайле

- **`/v1/media/metadata`**
  - Извлекает метаданные из медиафайлов (формат, кодеки, разрешение, битрейт)

### S3

- **`/v1/s3/upload`**
  - Загружает файлы в Amazon S3 хранилище напрямую из URL

### Toolkit

- **`/v1/toolkit/authenticate`**
  - Простая аутентификация для валидации API ключей

- **`/v1/toolkit/test`**
  - Проверяет корректность установки и работы API

- **`/v1/toolkit/job/status`**
  - Получает статус конкретной задачи по ID

- **`/v1/toolkit/jobs/status`**
  - Получает статус всех задач в указанном временном диапазоне

### Видео

- **`/v1/video/caption`**
  - Добавляет настраиваемые субтитры к видео с различными стилями

- **`/v1/video/concatenate`**
  - Объединяет несколько видео в один непрерывный файл

- **`/v1/video/thumbnail`**
  - Извлекает миниатюру из видео в указанной временной метке

- **`/v1/video/cut`**
  - Вырезает указанные сегменты из видеофайла

- **`/v1/video/split`**
  - Разделяет видео на несколько сегментов по указанным временным меткам

- **`/v1/video/trim`**
  - Обрезает видео, оставляя только контент между указанными временными метками

## Model Context Protocol (MCP)

Karpix Tools теперь поддерживает **Model Context Protocol (MCP)**, что позволяет ИИ-ассистентам (таким как Claude Desktop) напрямую использовать все инструменты API.

### Использование MCP

Сервер MCP находится в директории `karpix-mcp-server`. Он предоставляет доступ ко всем 31 инструменту API через единый интерфейс.

#### Настройка для Claude Desktop

Добавьте следующую конфигурацию в ваш файл `claude_desktop_config.json`. 

> [!TIP]
> Если вы переносите **Karpix API** на VPS, сам MCP-сервер лучше оставить на вашем локальном компьютере, просто изменив `KARPIX_BASE_URL` на адрес вашего сервера.

```json
{
  "mcpServers": {
    "karpix-tools": {
      "command": "node",
      "args": ["/ПУТЬ/К/ВАШЕМУ/ПРОЕКТУ/karpix-mcp-server/build/index.js"],
      "env": {
        "KARPIX_API_KEY": "ваш_api_ключ",
        "KARPIX_BASE_URL": "http://IP_ВАШЕГО_VPS:8080"
      }
    }
  }
}
```

> [!IMPORTANT]
> В поле `args` должен быть **полный абсолютный путь** к файлу `index.js` на том компьютере, где запущен Claude Desktop.

#### Сборка сервера

```bash
cd karpix-mcp-server
npm install
npm run build
```

## Сборка и запуск Docker

### Сборка Docker образа

```bash
docker build -t karpix-tools .
```

### Переменные окружения

#### Общие переменные

##### `API_KEY`
- **Назначение**: Используется для аутентификации API
- **Обязательность**: Обязательная

---

### Переменные для S3-совместимого хранилища

##### `S3_ENDPOINT_URL`
- **Назначение**: URL endpoint для S3-совместимого сервиса
- **Обязательность**: Обязательная при использовании S3

##### `S3_ACCESS_KEY`
- **Назначение**: Ключ доступа для S3-совместимого хранилища
- **Обязательность**: Обязательная при использовании S3

##### `S3_SECRET_KEY`
- **Назначение**: Секретный ключ для S3-совместимого хранилища
- **Обязательность**: Обязательная при использовании S3

##### `S3_BUCKET_NAME`
- **Назначение**: Имя bucket для S3-совместимого хранилища
- **Обязательность**: Обязательная при использовании S3

##### `S3_REGION`
- **Назначение**: Регион для S3-совместимого хранилища
- **Обязательность**: Обязательная при использовании S3 (допустимо значение "None" для некоторых провайдеров)

---

### Переменные для Google Cloud Storage (GCP)

##### `GCP_SA_CREDENTIALS`
- **Назначение**: JSON credentials для GCP Service Account
- **Обязательность**: Обязательная при использовании GCP

##### `GCP_BUCKET_NAME`
- **Назначение**: Имя GCP storage bucket
- **Обязательность**: Обязательная при использовании GCP

---

### Переменные настройки производительности

##### `MAX_QUEUE_LENGTH`
- **Назначение**: Ограничивает максимальное количество одновременных задач в очереди
- **По умолчанию**: 0 (без ограничений)
- **Рекомендация**: Установите значение в зависимости от ресурсов сервера, например 10-20 для небольших инстансов

##### `GUNICORN_WORKERS`
- **Назначение**: Количество worker процессов для обработки запросов
- **По умолчанию**: Количество ядер CPU + 1
- **Рекомендация**: 2-4× количество ядер CPU для CPU-зависимых нагрузок

##### `GUNICORN_TIMEOUT`
- **Назначение**: Timeout (в секундах) для worker процессов
- **По умолчанию**: 30
- **Рекомендация**: Увеличьте для обработки больших медиафайлов (например, 300-600)

---

### Конфигурация хранилища

##### `LOCAL_STORAGE_PATH`
- **Назначение**: Директория для временного хранения файлов во время обработки
- **По умолчанию**: /tmp
- **Рекомендация**: Укажите путь с достаточным дисковым пространством

##### `HF_HOME`
- **Назначение**: Директория для кэша моделей Hugging Face (Faster-Whisper)
- **По умолчанию**: /app/hf_cache
- **Рекомендация**: Используйте persistent volume для сохранения загруженных моделей между перезапусками

### Примечания
- Убедитесь, что все необходимые переменные окружения установлены в зависимости от используемого провайдера хранилища (GCP или S3)
- Отсутствие обязательных переменных приведет к ошибкам во время выполнения
- Переменные производительности можно настроить в зависимости от нагрузки и доступных ресурсов

### Запуск Docker контейнера

```bash
docker run -d -p 8080:8080 \
  # Аутентификация (обязательно)
  -e API_KEY=your_api_key \
  
  # Провайдер облачного хранилища (выберите один)

  # S3
  #
  #-e S3_ENDPOINT_URL=https://s3.ru1.storage.beget.cloud \
  #-e S3_ACCESS_KEY=your_access_key \
  #-e S3_SECRET_KEY=your_secret_key \
  #-e S3_BUCKET_NAME=your_bucket_name \
  #-e S3_REGION=ru1 \

  # Или

  # GCP Storage
  #
  #-e GCP_SA_CREDENTIALS='{"your":"service_account_json"}' \
  #-e GCP_BUCKET_NAME=your_gcs_bucket_name \
  
  # Конфигурация локального хранилища (опционально)
  -e LOCAL_STORAGE_PATH=/tmp \
  
  # Настройка производительности (опционально)
  -e MAX_QUEUE_LENGTH=10 \
  -e GUNICORN_WORKERS=4 \
  -e GUNICORN_TIMEOUT=300 \
  
  # Монтирование volume для кэша моделей (рекомендуется)
  -v hf_cache_volume:/app/hf_cache \
  
  karpix-tools
```

## Руководства по установке

API может быть развернут на различных облачных платформах:

### Digital Ocean

Digital Ocean App Platform довольно прост в настройке, но может стоить дороже других облачных провайдеров.

#### Важно: Длительные процессы

Необходимо использовать "webhook_url" (для любых запросов превышающих 1 минуту) в payload API для избежания таймаутов из-за CloudFlare proxy timeout.

При использовании webhook_url нет ограничений на длительность обработки.

### Google Cloud RUN Platform

Иногда сложен в установке (особенно на Google Business Workspaces), требует детальных настроек безопасности.

Однако это один из самых дешевых вариантов с отличной производительностью, так как оплата взимается только когда API обрабатывает запросы.

#### Важно: Запросы превышающие 5+ минут могут быть проблематичны

GCP Run завершит длительные процессы, что может произойти при обработке больших файлов (независимо от использования webhook_url).

Однако, когда время обработки стабильно меньше 5 минут (например, обработка только небольших файлов), работает отлично!

### Общие инструкции Docker

Вы можете использовать эти инструкции для развертывания на любом Linux сервере (на любой платформе).

Это позволяет более легко контролировать производительность и стоимость, но требует больше технических навыков для запуска.

## Тестирование API

1. Настройте переменные окружения:
   - `base_url`: URL вашего развернутого API
   - `x-api-key`: Ваш API ключ, настроенный при установке
2. Используйте примеры запросов для проверки корректности работы API
3. Проверьте endpoint `/v1/toolkit/test` для базовой проверки
