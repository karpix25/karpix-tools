# Karpix Tools MCP Server

MCP-сервер для архитектуры **Model Context Protocol**, предоставляющий доступ ко всем возможностям Karpix Tools API.

## Возможности

Этот сервер предоставляет 31 инструмент для работы с медиа-контентом, включая:
- **Видео**: обрезка, склейка, разделение, добавление субтитров, извлечение кадров.
- **Аудио**: объединение, микширование, конвертация в MP3.
- **Изображения**: создание видео из фото, скриншоты веб-страниц.
- **Медиа и ИИ**: транскрибация (Whisper), генерация ASS субтитров, получение метаданных.
- **Хранилище**: загрузка в Google Drive, S3 и GCP.

## Установка и запуск

### Предварительные условия
- Node.js (версия 18 или выше)
- Установленный и запущенный Karpix Tools API (по умолчанию на порту 8080)

### Сборка
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Соберите проект:
   ```bash
   npm run build
   ```

### Переменные окружения
- `KARPIX_API_KEY` (обязательно): Ваш ключ API для доступа к Karpix Tools.
- `KARPIX_BASE_URL` (опционально): Базовый URL API (по умолчанию `http://localhost:8080`).

## Использование с Claude Desktop

Добавьте сервер в конфигурацию `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "karpix-tools": {
      "command": "node",
      "args": ["/Users/nadaraya/Downloads/karpix-tools-main _2/karpix-mcp-server/build/index.js"],
      "env": {
        "KARPIX_API_KEY": "ваш_api_ключ",
        "KARPIX_BASE_URL": "http://localhost:8080"
      }
    }
  }
}
```
