## 1. Обзор

Эндпоинт `/v1/image/screenshot/webpage` позволяет создавать скриншоты веб-страниц с помощью библиотеки Playwright. Поддерживаются расширенные настройки: размер окна, эмуляция устройств, куки, заголовки, выбор конкретных элементов и инъекция JS/CSS. Скриншоты загружаются в облако.

## 2. Эндпоинт (Endpoint)

- **Путь URL:** `/v1/image/screenshot/webpage`
- **Метод HTTP:** `POST`

## 3. Запрос

### Заголовки (Headers)

- `x-api-key` (обязательно): Ваш ключ API.
- `Content-Type`: `application/json`

### Параметры тела запроса

- `url` (строка, обязательно*): URL страницы.
- `html` (строка, обязательно*): Прямой HTML-код для рендеринга.
  *Нужно указать либо `url`, либо `html`.
- `viewport_width` / `viewport_height`: Размер окна.
- `full_page` (boolean): Скриншот всей страницы (со скроллом).
- `format`: `png` или `jpeg`.
- `delay`: Задержка перед снимком (мс).
- `selector`: CSS-селектор элемента для снимка.
- `js` / `css`: Код для вставки на страницу перед снимком.
- `webhook_url`: Для асинхронного получения результата.

... полный список параметров аналогичен оригинальной документации.

### Пример запроса

```json
{
    "url": "https://example.com",
    "viewport_width": 1280,
    "full_page": true,
    "js": "document.body.style.background = 'red';",
    "id": "custom-job-123"
}
```

## 4. Ответ

Успешный ответ содержит URL изображения:

```json
{
  "code": 200,
  "response": "https://cloud.example.com/screenshot.png",
  "message": "success",
  ...
}
```

## 5. Обработка ошибок

- 400: Неверные параметры.
- 401: Ошибка авторизации.
- 429: Очередь полна.
- 500: Ошибка рендеринга или загрузки.

## 6. Примечания по использованию

- Используйте вебхуки для стабильности.
- Параметр `selector` позволяет «вырезать» только нужную часть страницы.
- `device_scale_factor: 2` создаст скриншот высокого качества (Retina).

## 7. Общие проблемы

- Селектор не найден (страница не успела загрузиться).
- Сайт блокирует запросы от серверных браузеров.
- Таймауты на тяжелых страницах.

## 8. Лучшие практики

- Тестируйте CSS-селекторы в консоли браузера перед отправкой в API.
- Используйте `wait_until: 'networkidle'` для страниц с большим количеством динамического контента.
- Используйте уникальные ID для каждой задачи.
