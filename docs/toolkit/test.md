# Тестовый API эндпоинт NCA Toolkit

## 1. Обзор

Эндпоинт `/v1/toolkit/test` предназначен для проверки корректности настройки API. Он создает временный файл, загружает его в облачное хранилище и возвращает URL загрузки. Это простейший тест работоспособности файловых операций и интеграции с облаком.

## 2. Эндпоинт (Endpoint)

**Путь URL:** `/v1/toolkit/test`
**Метод HTTP:** `GET`

## 3. Запрос

### Заголовки (Headers)

- `x-api-key` (обязательно): Ключ API для аутентификации.

### Параметры тела запроса

Параметры не требуются.

### Пример запроса

```bash
curl -X GET \
  https://your-api-url.com/v1/toolkit/test \
  -H 'x-api-key: your-api-key'
```

## 4. Ответ

### Успешный ответ

```json
{
  "endpoint": "/v1/toolkit/test",
  "code": 200,
  "response": "https://cloud-storage.com/success.txt",
  "message": "success",
  ...
}
```

### Ответы с ошибками

- **401 Unauthorized**: Неверный или отсутствующий ключ API.
- **500 Internal Server Error**: Ошибка при создании или загрузке файла.

## 5. Обработка ошибок

- **401**: Ошибка авторизации.
- **500**: Проблемы с правами доступа к диску или настройками облачного хранилища (S3/GCP).

## 6. Примечания по использованию

Этот эндпоинт используется только для диагностики при первичной установке или после изменения настроек (например, при смене бакета S3).

## 7. Общие проблемы

- Неверный ключ доступа.
- Ошибки конфигурации S3/GCP (неверные credentials или URL эндпоинта).

## 8. Лучшие практики

- Запускайте этот тест сразу после деплоя.
- Периодически используйте его для мониторинга «здоровья» подключения к облаку.
